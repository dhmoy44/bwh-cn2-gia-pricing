## DC6 还是 DC9：去程回程路由不一样

结论先给：大多数人选下单页默认的洛杉矶 DC9（USCA_9）就行，移动宽带用户更应该选 DC9。两个机房的差异在路由上：

- DC6（USCA_6）：整体容量和稳定性最好，回程方向（机房到国内）的全部流量，包括联通和移动，都走 CN2 GIA。但去程与中国移动没有直连对等，移动用户的去程延迟会偏高。
- DC9（USCA_9）：国内方向三网聚合，回程按运营商分流：电信走 CN2 GIA（AS4809），移动走 CMIN2（AS58807），联通走精品网（AS10099），并且对中国移动的入口有直连。
